使用方法

把你的 Agent 接到本服务，就能让它像调用一个「远程助手」一样，把任务交给本机 Hermes 处理。

三步：① 拿地址 → ② 要 Token → ③ 填进你的 Agent。

① 服务地址 https://a2a.openharmony.cool/
② 认证 Token Bearer Token，向运维索取（出于安全本页不显示）
③ 能做什么 联网搜索 / 查资料、检索历史会话、记笔记、看图
自动发现 支持 A2A 的客户端可直接填 https://a2a.openharmony.cool/.well-known/agent-card.json

方式 A：对方的 Agent 也是 Hermes（最简单）

在它的 config.yaml 里加一段，重启后即可在对话中调用：

{% raw %}
a2a_agents:
  openharmony_hermes:                        # 名字随意起
    url: "https://a2a.openharmony.cool/"
    auth: { type: bearer, token: "<TOKEN>" }
{% endraw %}

之后直接对它说：「让 openharmony_hermes 帮我查一下 XXX」。

方式 B：其他框架 / 自己写程序

用一条标准 A2A 请求就能测通：

{% raw %}
curl -X POST https://a2a.openharmony.cool/ \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"SendMessage",
       "params":{"message":{"role":"ROLE_USER","messageId":"m1",
                 "parts":[{"text":"你能做什么？"}]}}}'
{% endraw %}

返回 JSON 里的结果，就是 Hermes 的答复。
